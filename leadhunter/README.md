# 🎯 LeadHunter

Полуавтоматическая система для фриланса: парсит новые проекты **Kwork**,
пишет через **Google Gemini** готовый отклик под каждое ТЗ и присылает карточку
в ваш личный **Telegram-бот**. Вы проверяете текст и вручную отправляете отклик
на Kwork.

```
Kwork (ручной вход 1 раз через Playwright)
        ↓  сохранённая браузерная сессия (storage_state.json)
Парсер новых проектов Kwork
        ↓
Gemini генерирует отклик
        ↓
Aiogram-бот присылает карточку владельцу
        ↓
вы копируете и отправляете отклик вручную
```

Telegram-userbot, вход по номеру/коду и `.session` в проекте **не используются** —
только Bot API (токен от @BotFather) для доставки карточек.

---

## 🧱 Стек

- **Python 3.12+** · **asyncio**
- **Playwright** — парсинг проектов Kwork (сохранённая сессия, без хранения пароля)
- **Google Gemini API** — генерация откликов (бесплатный ключ)
- **Aiogram 3.x** — Telegram Bot API для доставки карточек и кнопок
- **SQLite** (aiosqlite) — дедупликация и история

## 🚀 Запуск (Windows / Linux / Mac)

```bash
# 1) Обновить код
git pull

# 2) Установить зависимости
pip install -r requirements.txt
playwright install chromium

# 3) Заполнить .env
#    Windows: copy .env.example .env    |    Linux/Mac: cp .env.example .env
#    Вписать BOT_TOKEN, OWNER_ID, GEMINI_API_KEY

# 4) Один раз войти в Kwork (откроется браузер — войдите руками, затем Enter)
python kwork_login.py

# 5) Запустить бота
python main.py
```

Запуск **неинтерактивный**: `main.py` не спрашивает код, не ждёт ввода и сразу
поднимает Kwork-парсер и Telegram-бот. Проекты с Kwork приходят карточками в бот
с готовым откликом — жмёте «🚀 Скопировать» и вставляете отклик на Kwork.

### Что вписать в `.env`

| Переменная | Что это | Где взять |
|---|---|---|
| `BOT_TOKEN` | токен бота-получателя | [@BotFather](https://t.me/BotFather) |
| `OWNER_ID` | ваш Telegram id | [@userinfobot](https://t.me/userinfobot) |
| `GEMINI_API_KEY` | ключ Google Gemini (бесплатный) | https://aistudio.google.com |
| `GEMINI_MODEL` | модель Gemini | по умолчанию `gemini-1.5-flash` |
| `KWORK_ENABLED` | включить парсинг Kwork | `true` |
| `KWORK_URL` | страница биржи/категории | по умолчанию `https://kwork.ru/projects` |
| `KWORK_POLL_INTERVAL` | период опроса, сек | по умолчанию `180` |
| `DATABASE_PATH` | файл базы SQLite | по умолчанию `leadhunter.db` |

## 🔧 Настройка фильтров

Заказы-мусор отсекаются автоматически (значения по умолчанию, при желании
задаются в `.env`):

- `MIN_BUDGET` — проекты с бюджетом ниже отсекаются (по умолчанию `2000`).
- `JUNK_PHRASES` — стоп-фразы («за отзыв» и т.п.), проекты с ними игнорируются.
- Бюджет парсится эвристически (`5 000 ₽`, `$100`, `договорная` → без значения).

Все проекты (в т.ч. отфильтрованные) сохраняются в SQLite со статусом
(`new` / `accepted` / `skipped` / `filtered`), поэтому повторно не обрабатываются.

## ⚙️ Тонкая настройка ИИ

- `GEMINI_MODEL` — модель Gemini (по умолчанию `gemini-1.5-flash`; можно указать
  любую доступную вашему ключу модель — меняется только в `.env`, без правок кода).
- `GEMINI_MAX_TOKENS` / `GEMINI_TEMPERATURE` — длина и «разнообразие» отклика.

Промпт настроен на короткий, жёсткий отклик без приветствий и клише
(`ai/responder.py`, `SYSTEM_PROMPT`).

---

## 🛡️ Устойчивость

- **Ретраи Gemini API** — временные сбои (429/5xx/сеть) повторяются с
  экспоненциальной задержкой; постоянные (400/403) обрываются сразу.
- **Алёрты владельцу** — бот уведомляет, если сессия Kwork истекла, страница
  не парсится или Gemini недоступен (с антиспам-троттлингом).
- **Истёкшая сессия Kwork** — парсер замечает редирект на страницу входа и
  просит выполнить `python kwork_login.py` заново.
- **Изоляция сбоев** — ошибка парсера или одного заказа не роняет остальное.

---

## ⚠️ Про селекторы Kwork

Kwork периодически меняет вёрстку, поэтому CSS-селекторы вынесены в начало
`parsers/kwork_parser.py` (`CARD_SELECTOR`, `TITLE_SELECTOR`, …). Если в логах
видно «карточки не найдены», а проекты на странице есть — обновите эти селекторы.
Ошибки разбора не роняют процесс: они логируются, парсер ждёт следующего опроса.

## 🐳 Docker (опционально)

Образ включает Playwright + Chromium.

```bash
cp .env.example .env         # заполнить ключи
docker compose up -d --build
docker compose logs -f
```

> Вход в Kwork (`kwork_login.py`) открывает видимое окно браузера, которого нет в
> контейнере. Выполните вход **на хосте** обычным `python kwork_login.py`, затем
> смонтируйте получившийся `storage_state.json` в контейнер. База (`leadhunter.db`)
> хранится на томе `./data`.

## 🧩 Расширение

Новый источник заказов — класс-наследник `BaseParser` в `parsers/`: в `run()`
вызывайте `await self.emit(order)` для каждого проекта и добавьте задачу в
`main.py`. Остальной конвейер (дедуп → фильтр → отклик → карточка) заработает сам.
