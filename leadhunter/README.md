# 🎯 LeadHunter

Система автопарсинга фриланс-заказов и генерации откликов через ИИ.

LeadHunter мониторит Telegram-чаты и биржу **Kwork**, отсеивает дубликаты и мусор,
пишет через **Claude** короткий и профессиональный отклик-решение под каждое ТЗ и
присылает готовую карточку в ваш личный Telegram-бот с кнопками
**[🚀 Скопировать / Отправить]** и **[❌ Скипнуть]**.

---

## 🧱 Стек

- **Python 3.12+** · **asyncio**
- **Telethon** — мониторинг Telegram-чатов (userbot)
- **Playwright** — парсинг заказов Kwork
- **Anthropic Claude API** — генерация откликов
- **Aiogram 3.x** — Telegram-бот доставки и управления
- **SQLite** (aiosqlite) — дедупликация и история

### Как это работает

```
 Telethon ─┐
           ├──▶ asyncio.Queue ──▶ дедуп ──▶ фильтр ──▶ Claude ──▶ карточка ──▶ Aiogram-бот
 Playwright┘         (SQLite)                          (отклик)                (владелец)
```

Парсеры складывают заказы в общую очередь; пайплайн обработки развязан с источниками,
поэтому добавить новый источник — это просто ещё один класс-наследник `BaseParser`.

## 🚀 Запуск

### 1. Зависимости

```bash
cd leadhunter
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium                          # браузер для Kwork-парсера
```

### 2. Конфигурация

```bash
cp .env.example .env
```

Заполните `.env` (подробности — в комментариях файла):

| Переменная | Что это | Где взять |
|---|---|---|
| `TG_API_ID`, `TG_API_HASH` | доступ userbot к Telegram | https://my.telegram.org |
| `TG_CHATS`, `TG_KEYWORDS` | чаты и ключевые слова | вручную |
| `BOT_TOKEN` | токен бота-получателя | [@BotFather](https://t.me/BotFather) |
| `OWNER_ID` | ваш Telegram id | [@userinfobot](https://t.me/userinfobot) или `/start` боту |
| `ANTHROPIC_API_KEY` | ключ Claude API | https://console.anthropic.com |
| `KWORK_*` | биржа Kwork (опционально) | `KWORK_ENABLED=true` для включения |

### 3. Старт

```bash
python main.py
```

При первом запуске Telethon запросит код подтверждения (и, при 2FA, пароль) —
создастся файл сессии `*.session`. Дальше — вход автоматический.

## 🐳 Запуск в Docker

Образ уже включает Playwright + Chromium — отдельная установка не нужна.

```bash
cd leadhunter
cp .env.example .env        # заполнить ключи

# 1) Первичная авторизация Telethon (интерактивно — ввести код из Telegram).
#    Сессия и база сохранятся в ./data и переживут пересборки.
docker compose run --rm leadhunter

# 2) Обычный фоновый запуск:
docker compose up -d --build

# Логи / остановка:
docker compose logs -f
docker compose down
```

Сессия Telethon (`./data/leadhunter.session`) и база (`./data/leadhunter.db`)
лежат на томе `./data`, поэтому не теряются при пересборке контейнера.
`restart: unless-stopped` поднимает сервис после падения или перезагрузки хоста.

## 🔧 Настройка фильтров

- `MIN_BUDGET` — заказы с бюджетом ниже отсекаются.
- `JUNK_PHRASES` — стоп-фразы (например, «за отзыв»), заказы с ними игнорируются.
- Бюджет парсится эвристически (`5 000 ₽`, `$100`, `договорная` → без значения).

Отфильтрованные и обработанные заказы сохраняются в SQLite со статусом
(`new` / `accepted` / `skipped` / `filtered`), поэтому повторно они не обрабатываются.

## ⚙️ Тонкая настройка ИИ

Генерация управляется через `.env`:

- `ANTHROPIC_MODEL` — модель (по умолчанию `claude-opus-4-8`).
- `ANTHROPIC_THINKING` — адаптивное мышление (`true` — качественнее, дороже).
- `ANTHROPIC_EFFORT` — глубина проработки: `low` … `max`.

Промпт настроен на короткий, жёсткий отклик без приветствий, вводных слов и клише
(`ai/responder.py`, константа `SYSTEM_PROMPT`).

## 🛡️ Устойчивость: ретраи и алёрты

- **Ретраи Claude API.** Временные сбои (429 rate limit, 5xx, сеть/таймаут)
  повторяются с экспоненциальной задержкой (`core/retry.py`). Постоянные
  ошибки (400/401/403) обрываются сразу — без бессмысленных повторов.
  Настройка: `RETRY_ATTEMPTS`, `RETRY_BASE_DELAY`.
- **Алёрты владельцу.** Бот присылает уведомление, если парсер аварийно упал,
  Kwork не удаётся распарсить или Claude недоступен после ретраев. Однотипные
  алёрты троттлятся (`ALERT_COOLDOWN`, по умолчанию раз в 5 минут), чтобы не спамить.
- **Изоляция сбоев.** Падение одного парсера не роняет остальные компоненты
  (`BaseParser.run_safe`); ошибка обработки одного заказа не прерывает очередь.

## ⚠️ Замечания по эксплуатации

- **Telethon** работает как userbot от вашего аккаунта — используйте на свой риск и
  соблюдайте правила Telegram. Файл `*.session` — это доступ к аккаунту, не коммитьте его.
- **Kwork** периодически меняет вёрстку и часто требует авторизацию для доступа к бирже.
  CSS-селекторы вынесены в начало `parsers/kwork_parser.py` — при поломке парсинга
  обновляйте их там. Ошибки селекторов не роняют процесс.
- `.env`, `*.session` и `*.db` уже в `.gitignore` — секреты в репозиторий не попадут.

## 🧩 Расширение

Новый источник заказов:

1. Создайте класс-наследник `BaseParser` в `parsers/`.
2. В методе `run()` вызывайте `await self.emit(order)` для каждого заказа.
3. Зарегистрируйте задачу в `main.py` рядом с существующими парсерами.

Вся остальная цепочка (дедуп → фильтр → отклик → карточка) заработает автоматически.
