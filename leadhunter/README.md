# 🎯 LeadHunter

Полуавтоматическая система поиска фриланс-заказов на **международных площадках**.
Собирает свежие лиды из RSS/Atom-фидов (Upwork saved-search RSS, удалённые
джоб-борды и любой RSS-источник), пишет через **Google Gemini** профессиональный
отклик на английском и присылает карточку в ваш **Telegram-бот**. Вы проверяете
текст и вручную отправляете отклик заказчику.

```
RSS-фиды международных площадок (Upwork RSS, джоб-борды, …)
        ↓  отбор по ключевым словам (Python, automation, scraping, bot, …)
Gemini генерирует отклик (English)
        ↓
Aiogram-бот присылает карточку владельцу
        ↓
вы копируете и отправляете отклик вручную
```

Без скрапинга браузером, капчи и логинов по кукам — только официальные фиды и
Telegram Bot API (токен от @BotFather) для доставки.

---

## 🧱 Стек

- **Python 3.12+** · **asyncio**
- **feedparser** — чтение RSS/Atom-фидов (модульный список источников)
- **Google Gemini API** — генерация откликов (бесплатный ключ)
- **Aiogram 3.x** — Telegram Bot API для доставки карточек и кнопок
- **SQLite** (aiosqlite) — дедупликация и история

## 🚀 Запуск (Windows / Linux / Mac)

```bash
# 1) Обновить код
git pull

# 2) Установить зависимости
pip install -r requirements.txt

# 3) Заполнить .env
#    Windows: copy .env.example .env    |    Linux/Mac: cp .env.example .env
#    Вписать BOT_TOKEN, OWNER_ID, GEMINI_API_KEY (и, при желании, FEEDS)

# 4) Запустить
python main.py
```

Никаких логинов и кодов: `main.py` сразу поднимает RSS-парсер и Telegram-бот.
Подходящие лиды приходят карточками в бот с готовым откликом на английском —
жмёте «🚀 Скопировать» и отправляете отклик на площадке.

### Что вписать в `.env`

| Переменная | Что это | Где взять / значение |
|---|---|---|
| `BOT_TOKEN` | токен бота-получателя | [@BotFather](https://t.me/BotFather) |
| `OWNER_ID` | ваш Telegram id | [@userinfobot](https://t.me/userinfobot) |
| `GEMINI_API_KEY` | ключ Google Gemini (бесплатный) | https://aistudio.google.com |
| `GEMINI_MODEL` | модель Gemini | по умолчанию `gemini-1.5-flash` |
| `FEEDS` | список RSS-фидов через запятую | по умолчанию — публичные джоб-борды |
| `FEED_POLL_INTERVAL` | период опроса фидов, сек | по умолчанию `300` |
| `KEYWORDS` | ключевые слова отбора | `Python, automation, scraping, bot, text editing, proofreading` |
| `MIN_BUDGET` | мин. бюджет в USD | по умолчанию `50` |
| `DATABASE_PATH` | файл базы SQLite | по умолчанию `leadhunter.db` |

## 🌐 Источники лидов (FEEDS)

`FEEDS` — это список URL RSS/Atom-фидов через запятую. Из коробки заданы два
публичных фида удалённых вакансий, так что бот работает сразу.

**Upwork.** Откройте нужный поиск или Saved Search на Upwork и возьмите ссылку
RSS этого поиска — она содержит ваш `securityToken`/`userUid`/`orgUid`. Вставьте
её в `FEEDS`, например:

```
FEEDS=https://www.upwork.com/ab/feed/jobs/rss?q=python%20automation&sort=recency&securityToken=...&userUid=...&orgUid=...
```

**Другие площадки.** Добавляйте любой RSS/Atom-фид — источник модульный. Для
площадок без RSS используйте фид-агрегатор вакансий по нужным ключевым словам.

Отбор по `KEYWORDS` применяется к заголовку и описанию каждого лида — публикуются
только совпадения. Бюджет распознаётся из сумм вида `$150`; лиды без явной суммы
проходят (бюджет фильтруется только когда он распознан и ниже `MIN_BUDGET`).

## ⚙️ Тонкая настройка ИИ

- `GEMINI_MODEL` — модель Gemini (по умолчанию `gemini-1.5-flash`; можно указать
  любую доступную вашему ключу модель — меняется только в `.env`, без правок кода).
- `GEMINI_MAX_TOKENS` / `GEMINI_TEMPERATURE` — длина и «разнообразие» отклика.

Промпт (`ai/responder.py`, `SYSTEM_PROMPT`) настроен на короткий профессиональный
отклик **на английском** (или на языке вакансии), без приветствий и клише —
убедительный для зарубежных заказчиков.

---

## 🛡️ Устойчивость

- **Ретраи Gemini API** — временные сбои (429/5xx/сеть) повторяются с
  экспоненциальной задержкой; постоянные (400/403) обрываются сразу.
- **Graceful failure** — при любой ошибке Gemini (в т.ч. `429 quota`) генерация
  возвращает `None`: карточка уходит с пометкой «сформулируй вручную», пайплайн
  не падает.
- **Ошибка одного фида** не роняет остальные и логируется; владелец получает алёрт
  (с антиспам-троттлингом).
- **Дедупликация** — каждый лид проверяется в SQLite по (source, external_id),
  повторные записи из фида не обрабатываются.

## 🧩 Расширение

Новый источник — либо ещё один URL в `FEEDS`, либо класс-наследник `BaseParser`
в `parsers/`: в `run()` вызывайте `await self.emit(order)` для каждого лида и
добавьте задачу в `main.py`. Остальной конвейер (дедуп → фильтр → отклик →
карточка) заработает сам.
